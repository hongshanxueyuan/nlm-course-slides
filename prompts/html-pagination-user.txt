## 任务

根据下方 Markdown 文档的内容边界，将正文切分成适合逐页阅读的页面原文。每页只输出该页对应的原文 `content`。

## 切分要求

* **完整保留原文**：每页 `content` 必须是输入文档中的连续原文片段，保留原有标题、句子、列表、表格、代码块和 Markdown 格式；不改写、不概括、不润色、不补充。
* **完整覆盖且顺序一致**：所有页面按原文顺序排列。按顺序查看各页时，原文中每个非空字符都应恰好出现一次；不遗漏、不重复、不调换。
* **保留原文重复**：原文中重复出现的标题、句子、术语或段落都照常保留。页面之间可以出现相同文字，只要这些文字在原文中也分别出现。
* **按内容边界切分**：优先在原有段落或 Markdown 块之间分页。标题与其后紧邻的正文放在同一页；列表、表格和代码块尽量保持完整。避免在句子或段落中间切分。
* **上级正文与下级标题分开分页**：按 Markdown 标题层级识别上下级关系。若上级标题下、首个小标题前有正文（包括段落、表格或列表），上级标题和这部分正文单独成页；首个小标题从下一页开始，不要把它们合并到同一页。同一上级标题下的同级小标题各自另起一页，并与各自正文放在一起。用作小标题的编号项（如独立成标题的 `1、`、`2、`、`3、`）也按此规则处理；普通编号列表仍作为完整列表处理。若上级标题后直接跟小标题、没有正文，可将上级标题与第一个小标题放在同一页，避免生成只有标题的页面。
* **页面主题清楚**：优先让每页覆盖一个连续、完整的主题；不为追求页面独立性删除上下文或原文内容。
* **最多 19 页正文**：最终页面清单会另加一页课程封面。只有按上述内容边界切分会超过 19 页正文时，才合并相邻页面；合并后仍完整保留原文及先后顺序。
* **不另造内容**：页面只包含原文，不添加新的标题、总结、页码、开场或收尾内容。原文已有的总结、行动项及其他内容全部保留在原有位置。

## 文档内容

```markdown
{text}
```

## 输出格式

严格输出 JSON，不要附加解释：

```json
{"pages":[{"content":"本页原文"},{"content":"下一页原文"}]}
```

`pages` 按正文顺序排列；每个 `content` 都是对应页面的原文片段，不含分页标记。
